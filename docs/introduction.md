Simple Astrology App is a desktop application to render an astrology birth chart given the required input data from the user. It is as its namesake, simple. It is not a competitor to [astro.com](https://astro.com), [solar-fire](https://alabe.com/solarfireV9.html) or any other feature rich astrology software or website, however, if you just want to render a birth chart for yourself or someone you love, then this software may be useful to you.

I wrote this software initially because I could not find a compiled, binary application to render a birth chart for my Debian Linux based desktop computer. I have web framework software development experience and decided to create the application using some of these frameworks. This is the first  web framework desktop application I have developed. You can look at this page to see the frameworks and tools that I used.
