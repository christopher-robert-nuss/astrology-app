# Save, load, and print

A chart is a `.json` file on your computer. It stores the birth data and the chart that was drawn from it. The app does not keep a library of its own.

Generate a chart before you save or print. The File menu asks you to generate one first if the workspace is empty.

## Save

**File → Save** writes the open chart. The first save asks for a folder and a file name. The suggested name is the chart name, or `chart.json`. Later saves write that same file.

**File → Save As...** asks for a new file and leaves the previous file as it was.

## Open

**File → Open...** reads a chart file and draws it again from the birth data in that file.

**File → Recent Files** lists the last files you saved or opened, up to ten. Choosing one opens it. The menu shows **No Recent Files** until you have saved or opened a chart.

## New chart

**File → New Chart** clears the wheel and opens **Enter Birth Data**. It does not delete a file you already saved.

## Print

**File → Print...** prints the chart that is on screen. It uses the system print dialog, so you can choose a printer or save a PDF from there.
